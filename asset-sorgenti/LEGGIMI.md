# Immagini sorgente

Metti qui le immagini generate con Gemini, con i nomi indicati in `docs/ASSET-GEMINI.md`.
Poi esegui `npm run assets`: le immagini pronte finiscono in `public/assets/` e l'app le usa subito.

Le immagini messe qui dal computer sono escluse da git (`.gitignore`): si pubblicano le versioni elaborate in `public/assets/`.
Quelle caricate dal sito di GitHub entrano invece nel repository: va bene, così chiunque può rigenerare gli asset.
