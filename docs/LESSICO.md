# Lessico di Territorial Quest

Parole uniche, scritte allo stesso modo in tutta l'interfaccia. Frasi brevi, seconda persona, verbi d'azione.
Mai il punto mediano (·), mai l'inglese dove esiste l'italiano.

| Si dice | Non si dice | Che cos'è |
|---|---|---|
| **campagna** | progetto, gioco, sessione | Un'attività sul territorio, con le sue date e le sue aree |
| **uscita** | sessione, walk, partita | Un giro a piedi: si parte e si rientra |
| **rilievo** | osservazione, dato, contributo (in gioco) | Ciò che si raccoglie sul posto o da una fonte |
| **raccogliere** | inserire, caricare | Il gesto di fare un rilievo |
| **conferma, confermare** | validazione, validare | Un'altra squadra verifica un rilievo sul posto: solo allora vale punti |
| **squadra** | team, gruppo | Chi gioca insieme. «Team» resta solo nei dati e nei file |
| **zona** | cella, esagono, H3 | Un pezzo di territorio della griglia. «Cella H3» solo nei dati tecnici |
| **accesa, accendere** | esplorata, coperta | Una zona attraversata o con rilievi |
| **luogo** | punto di interesse, POI | Una meta da raggiungere, con il suo racconto |
| **percorso** | itinerario, route | Luoghi da raggiungere in ordine |
| **indagine sul sito** | scheda, survey, form | Le domande da compilare presso un luogo |
| **regia** | master, admin, pannello di controllo | Chi organizza e guida la campagna |
| **contributo** | segnalazione | Ciò che chiunque aggiunge dalla mappa pubblica, letto dalla regia prima di comparire |
| **mappa pubblica** | stage, dashboard | La mappa dei risultati, per tutti |
| **Campo** | Field | L'app per chi è in giro |
| **sul posto, da fonti, sensazioni** | Field, Desk, Feel | Le tre famiglie di rilievo |
| **Zaino** | menu | Tutte le funzioni di chi gioca |
| **Diario** | storico, log | Le proprie raccolte, giorno per giorno |
| **Atlante** | collezione, Pokédex | Forme, tipi di luogo e ambienti trovati dal gruppo |

## Tono

- **Concreto**: «Scatti adesso, scrivi due righe quando ti fermi», non «Acquisizione rapida con completamento differito».
- **Cooperativo**: si parla del gruppo, mai di vincere contro qualcuno. «Punti insieme», non «classifica».
- **Breve**: un'idea per frase. Titoli di 3–6 parole.
- **Onesto sui dati**: dire sempre che cosa si salva e che cosa no («il tracciato non viene salvato»).
